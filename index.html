Why Choose ConfessionBot?

100% Anonymous

Confessions are completely anonymous to the public. Only server admins can see who submitted what for moderation purposes.

Safe & Secure

Built with privacy in mind. Your data is protected and the bot follows Discord's best security practices.

Easy Setup

Get started in minutes. Simple slash commands make configuration a breeze for server administrators.

Admin Control

Full admin oversight with private logging channels. Monitor confessions while maintaining user anonymity.

Multi-Server

Works across multiple Discord servers with independent configurations for each community.

Free Forever

Completely free to use. No hidden fees, no premium tiers. Built by the community, for the community.

How It Works

1

Add Bot to Server

Click "Add to Discord" and select your server. Grant necessary permissions.

2

Configure Channels

Use /setconfig to set your confession and admin channels.

3

Start Confessing

Users can now use /confess to submit anonymous confessions to your community.
